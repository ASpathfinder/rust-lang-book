# 智能指针

<em>指针(pointer)</em>是一个通用概念，指包含内存地址的变量。这个地址引用或“指向”其他数据。Rust 中最常见的指针是第 4 章介绍过的引用。引用由 `&` 符号表示，并借用其指向的值。除了引用数据之外，它们没有任何特殊能力，也不会产生开销。

而<em>智能指针(smart pointer)</em>是行为类似指针、但还具有额外元数据和能力的数据结构。智能指针并非 Rust 独有：它起源于 C++，也存在于其他语言中。Rust 标准库定义了多种智能指针，提供超越引用的功能。为了探索这一通用概念，我们会考察几个不同的智能指针示例，包括<em>引用计数(reference counting)</em>智能指针类型。这种指针通过跟踪所有者数量，使数据可以拥有多个所有者，并在没有所有者时清理数据。

在具有所有权和借用概念的 Rust 中，引用与智能指针还有一项区别：引用只借用数据，而智能指针在许多情况下<em>拥有</em>其指向的数据。

智能指针通常使用结构体实现。与普通结构体不同，智能指针会实现 `Deref` 和 `Drop` 特征。`Deref` 特征让智能指针结构体的实例可以像引用一样工作，使代码既能处理引用，也能处理智能指针。`Drop` 特征允许你自定义智能指针实例离开作用域时运行的代码。本章会讨论这两个特征，并展示它们对智能指针为何重要。

智能指针模式是 Rust 中经常使用的通用设计模式，因此本章不会涵盖所有现有智能指针。许多库都有自己的智能指针，你甚至可以自行编写。我们会介绍标准库中最常见的智能指针：

- `Box<T>`：在堆上分配值
- `Rc<T>`：支持多重所有权的引用计数类型
- `Ref<T>` 和 `RefMut<T>`：通过 `RefCell<T>` 访问；`RefCell<T>` 在运行时而不是编译时强制执行借用规则

此外，我们还会介绍<em>内部可变性(interior mutability)</em>模式，其中不可变类型会公开用于修改内部值的 API。还会讨论引用循环：它们如何造成内存泄漏，以及如何防止它们。
