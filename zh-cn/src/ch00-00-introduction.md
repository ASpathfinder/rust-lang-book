欢迎阅读《Rust 程序设计语言》，一本介绍 Rust 的入门书。Rust 编程语言能够
帮助你编写速度更快、可靠性更高的软件。在编程语言设计中，高层次的<em>易用性
(ergonomics)</em>和底层控制往往难以兼得，而 Rust 对这种矛盾发起了挑战。Rust
在强大的技术能力与良好的开发者体验之间取得平衡，使你既可以掌控内存使用等
底层细节，又不必承受这类控制方式历来伴随的种种麻烦。

## Rust 适合哪些人

Rust 因许多不同的原因而适合许多人。下面来看几个最重要的群体。

### 开发者团队

对于<em>系统编程(systems programming)</em>知识水平不一的大型开发者团队，Rust
正在成为一种高效的协作工具。底层代码很容易出现各种隐蔽的错误；在大多数
其他语言中，只有经验丰富的开发者进行大量测试和细致的代码审查，才可能发现
这些错误。在 Rust 中，<em>编译器(compiler)</em>会充当守门人：含有这类隐蔽错误的
代码——包括<em>并发(concurrency)</em>错误——会被拒绝编译。团队与编译器协同工作，
便可以把时间花在程序逻辑上，而不是四处追查错误。

Rust 还把现代化的开发工具带入了系统编程领域：

- Cargo 是 Rust 自带的<em>依赖管理器(dependency manager)</em>和构建工具，让开发者
  能够在整个 Rust 生态系统中轻松且一致地添加、编译和管理依赖。
- `rustfmt` 格式化工具可确保不同开发者采用一致的代码风格。
- Rust Language Server 为<em>集成开发环境(IDE)</em>提供代码补全和行内错误信息等
  集成功能。

借助这些工具以及 Rust 生态系统中的其他工具，开发者在编写系统级代码时也能
保持高效。

### 学生

Rust 适合学生，也适合有兴趣学习系统相关概念的人。许多人借助 Rust 学会了
操作系统开发等主题。Rust 社区非常友好，也乐于解答学生的问题。通过本书等
工作，Rust 各团队希望让更多人——尤其是编程新手——更容易接触系统相关概念。

### 公司

数百家大大小小的公司都在生产环境中使用 Rust 完成各种任务，包括命令行工具、
Web 服务、DevOps 工具、嵌入式设备、音视频分析和转码、加密货币、生物信息学、
搜索引擎、物联网应用、机器学习，甚至 Firefox Web 浏览器的重要组成部分。

### 开源开发者

Rust 适合希望参与构建 Rust 编程语言、社区、开发工具和库的人。我们非常欢迎
你为 Rust 语言作出贡献。

### 重视速度和稳定性的人

Rust 适合重视语言速度和稳定性的人。这里的“速度”既指 Rust 代码的运行速度，
也指 Rust 让你编写程序的速度。Rust 编译器的检查能够在添加功能和重构时保障
稳定性。与之相反，缺少这类检查的语言往往留下脆弱的旧代码，开发者甚至不敢
修改。Rust 致力于提供<em>零成本抽象(zero-cost abstractions)</em>：高级特性编译为
底层代码后，与手工编写的代码一样快，从而努力让安全的代码也能保持高性能。

Rust 还希望为许多其他用户提供支持；上面提到的只是其中最主要的群体。总的
来说，Rust 最大的愿景，是同时提供安全性与生产力、速度与易用性，消除程序员
数十年来不得不接受的取舍。试一试 Rust，看看它所作的选择是否适合你。

## 本书适合哪些读者

本书假定你曾使用其他编程语言编写代码，但不要求你掌握某一种特定语言。我们
努力让来自各种编程背景的读者都能理解这些内容。本书不会花太多篇幅解释编程
究竟是什么，也不会介绍应该怎样思考编程。如果你完全没有编程经验，最好先
阅读一本专门介绍编程的书。

## 如何使用本书

一般而言，本书假定你会从头到尾依次阅读。后面的章节建立在前面介绍的概念之
上；前面的章节可能暂不深入讨论某个主题，而在后面的章节中再回过头来详述。

本书包含两类章节：概念章节和项目章节。在概念章节中，你会学习 Rust 的某个
方面；在项目章节中，我们会一起编写小程序，运用此前学到的知识。第 2、12、
21 章是项目章节，其余都是概念章节。

<strong>第 1 章</strong>介绍如何安装 Rust、如何编写“Hello, world!”程序，以及如何使用
Rust 的<em>包管理器(package manager)</em>和构建工具 Cargo。<strong>第 2 章</strong>让你亲手构建
一个猜数字游戏，以实践方式开始编写 Rust 程序。我们会在这里从较高层次介绍
一些概念，后续章节再提供更多细节。如果你想立刻动手，第 2 章就是合适的起点。
如果你是一位格外严谨、喜欢先学完每个细节再继续的读者，也可以跳过第 2 章，
直接阅读介绍 Rust 与其他编程语言相似特性的<strong>第 3 章</strong>；等你想通过项目运用
学到的细节时，再回到第 2 章。

在<strong>第 4 章</strong>中，你会学习 Rust 的所有权系统。<strong>第 5 章</strong>讨论结构体和方法。
<strong>第 6 章</strong>介绍枚举、`match` 表达式，以及 `if let` 和 `let...else` 控制流
结构。你将使用结构体和枚举创建自定义类型。

在<strong>第 7 章</strong>中，你会学习 Rust 的模块系统，以及用于组织代码及其公开应用
<em>程序编程接口(API)</em>的私有性规则。<strong>第 8 章</strong>讨论标准库提供的一些常用集合数据
结构：vector、字符串和哈希映射。<strong>第 9 章</strong>探讨 Rust 的错误处理理念和技术。

<strong>第 10 章</strong>深入介绍泛型、trait 和生命周期，它们使你能够定义适用于多种类型
的代码。<strong>第 11 章</strong>专门讨论测试；即使 Rust 提供了安全保证，仍需要测试来
确保程序逻辑正确。在<strong>第 12 章</strong>中，我们会自行实现命令行工具 `grep` 的部分
功能，用来搜索文件中的文本。为此，我们将使用前面章节讨论过的许多概念。

<strong>第 13 章</strong>探讨闭包和迭代器，即 Rust 从函数式编程语言中吸收的特性。在
<strong>第 14 章</strong>中，我们会更深入地研究 Cargo，并讨论与他人共享库的最佳实践。
<strong>第 15 章</strong>介绍标准库提供的智能指针，以及支持其功能的 trait。

在<strong>第 16 章</strong>中，我们会逐一介绍不同的并发编程模型，讨论 Rust 如何帮助你
从容地进行多线程编程。在此基础上，<strong>第 17 章</strong>将探讨 Rust 的 async 和 await
语法，以及任务、future 和 stream，还有它们所支持的轻量级并发模型。

<strong>第 18 章</strong>比较 Rust 的惯用写法与你可能熟悉的面向对象编程原则。<strong>第 19
章</strong>是关于模式与模式匹配的参考资料；它们是在 Rust 程序中表达思想的强大方式。
<strong>第 20 章</strong>汇集了许多值得关注的高级主题，包括 unsafe Rust、宏，以及有关
生命周期、trait、类型、函数和闭包的更多内容。

在<strong>第 21 章</strong>中，我们将完成一个项目，实现一个底层多线程 Web 服务器！

最后，若干附录以更接近参考手册的形式提供有关 Rust 的实用信息。<strong>附录 A</strong>
介绍 Rust 关键字，<strong>附录 B</strong>介绍 Rust 的运算符和符号，<strong>附录 C</strong>介绍标准库
提供的可派生 trait，<strong>附录 D</strong>介绍一些实用开发工具，<strong>附录 E</strong>解释 Rust
Edition。你可以在<strong>附录 F</strong>中找到本书的其他翻译版本；<strong>附录 G</strong>则介绍 Rust
是如何开发出来的，以及 nightly Rust 是什么。

阅读本书没有错误的方式：想跳到后面就尽管去读！如果遇到困惑，你可能需要
回头查看前面的章节，但最重要的是选择适合自己的方式。

学习 Rust 的一个重要环节，是学会阅读编译器显示的错误信息；它们会引导你写出
可以正常工作的代码。因此，本书会给出许多无法编译的示例，并展示编译器在每种
情况下给出的错误信息。请注意，随意挑选并运行一个示例时，它可能无法编译！
务必阅读示例附近的文字，确认你尝试运行的示例是否本来就应该报错。在大多数
情况下，我们会继续给出无法编译代码的正确版本。Ferris 也会帮助你分辨哪些
代码本来就不应该正常工作：
