# 前言

短短几年间，Rust 编程语言已经走过了很长一段路：它从一个规模尚小、初具
雏形的爱好者社区中诞生并成长，如今已成为全世界最受喜爱、需求最旺盛的
编程语言之一。回望过去，Rust 的力量和潜力注定会引人注目，并在<em>系统编程
(systems programming)</em>领域站稳脚跟；但开源社区对它的兴趣与创新能够遍及
全球，继而推动各行各业大规模采用 Rust，却绝非必然。

如今，我们很容易列举 Rust 提供的众多优秀特性，解释这种兴趣和采用率为何
会迅速增长。谁会不想同时拥有<em>内存安全(memory safety)</em>、快速的性能、友好的
<em>编译器(compiler)</em>、出色的工具，以及其他许多优秀特性呢？你今天看到的 Rust
语言，融合了多年来的系统编程研究成果和一个充满活力与热情的社区所积累的
实践智慧。这门语言目标明确、设计用心，为开发者提供了一种工具，让编写安全、
快速且可靠的代码变得更加容易。

然而，Rust 真正的独特之处，在于它从根本上致力于赋能每一位用户，帮助你实现
自己的目标。这是一门希望你取得成功的语言；赋能这一原则也贯穿了构建、维护
并倡导这门语言的整个社区。自这部权威著作的上一版问世以来，Rust 进一步发展
为一门真正全球化、值得信赖的语言。Rust 项目现在得到了 Rust 基金会的有力
支持；基金会还会投资关键项目，以确保 Rust 安全、稳定且可持续。

这一版《Rust 程序设计语言》是一次全面更新，既反映了这门语言多年来的演进，
也提供了宝贵的新内容。但它不仅仅是一本语法和库的指南，更是一份邀请，邀请你
加入一个重视质量、性能与周全设计的社区。无论你是第一次探索 Rust 的资深
开发者，还是希望进一步提升技能、已经富有经验的 Rustacean，本版都能为你
带来收获。

Rust 的发展历程始终围绕协作、学习和迭代展开。这门语言及其生态系统的成长，
直接映照出背后那个充满活力、多元化的社区。从核心语言设计者到偶尔参与的
贡献者，数千名开发者共同造就了 Rust 这一独特而强大的工具。当你翻开本书时，
你不只是在学习一门新的编程语言，也是在加入一场让软件变得更好、更安全、
开发起来更愉快的行动。

欢迎加入 Rust 社区！

- Rust 基金会执行董事 Bec Rumbul
