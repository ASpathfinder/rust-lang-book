# 进一步了解 Cargo 与 Crates.io

到目前为止，我们只使用了 Cargo 最基本的功能来构建、运行和测试代码，但它能做的远不止这些。本章会讨论其他一些更高级的功能，展示如何：

- 通过发布配置自定义构建。
- 在 [crates.io](https://crates.io/) 上发布库。
- 使用工作区组织大型项目。
- 从 [crates.io](https://crates.io/) 安装二进制文件。
- 使用自定义命令扩展 Cargo。

除了本章介绍的功能，Cargo 还能完成更多事情；有关其全部功能的完整说明，请参阅 [Cargo 文档](https://doc.rust-lang.org/cargo/)。
