# 常见编程概念

本章介绍几乎所有编程语言都会出现的概念，以及它们在 Rust 中的工作方式。许多
编程语言的核心内容都很相似。本章没有 Rust 独有的概念，但我们会在 Rust 语境
下讨论它们，并说明相关的使用惯例。

具体来说，你会学习变量、基本类型、函数、注释和控制流。这些基础会出现在每个
Rust 程序中；尽早掌握它们，可以为后续学习打下坚实基础。

> #### 关键字
>
> 与其他语言类似，Rust 保留了一组只供语言本身使用的<em>关键字(keyword)</em>。请
> 注意，不能把这些词用作变量名或函数名。大多数关键字具有特殊含义，你会在
> Rust 程序中用它们完成各种任务；少数关键字目前没有对应功能，而是为将来
> 可能加入 Rust 的功能预留。完整列表参见[附录 A][appendix_a]<!-- ignore -->。
