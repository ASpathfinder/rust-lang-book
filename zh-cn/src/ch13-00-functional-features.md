# 函数式语言功能：迭代器与闭包

Rust 的设计从许多现有语言和技术中汲取灵感，其中一项重要影响来自<em>函数式编程(functional programming)</em>。以函数式风格编程时，通常会把函数当作值使用，例如通过实参传递函数、从其他函数返回函数、把函数赋给变量以便稍后执行，等等。

本章不会争论什么是或不是什么函数式编程，而会讨论 Rust 中一些与许多通常称为函数式语言的语言相似的功能。

具体来说，我们会介绍：

- <em>闭包(closure)</em>：一种类似函数、可以存储在变量中的结构
- <em>迭代器(iterator)</em>：一种处理一系列元素的方式
- 如何使用闭包和迭代器改进第 12 章的 I/O 项目
- 闭包和迭代器的性能（先透露一下：它们比你想象得更快！）

我们已经介绍过模式匹配、枚举等其他同样受函数式风格影响的 Rust 功能。掌握闭包和迭代器是编写快速、惯用 Rust 代码的重要组成部分，因此会用整章介绍它们。
