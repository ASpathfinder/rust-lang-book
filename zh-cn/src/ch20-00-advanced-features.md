# 高级功能

到现在为止，你已经学习了 Rust 编程语言中最常用的部分。在第 21 章再完成一个项目之前，我们将先了解语言中一些偶尔可能遇到、但未必每天都会使用的方面。当你碰到不熟悉的内容时，可以把本章当作参考。这里介绍的功能适用于非常具体的场景。尽管你可能不会经常使用它们，我们仍希望确保你了解 Rust 提供的全部功能。

本章将介绍：

- 不安全 Rust：如何选择不使用 Rust 的部分保证，并自行承担维护这些保证的责任
- 高级 trait：关联类型、默认类型参数、完全限定语法、超 trait，以及与 trait 相关的 newtype 模式
- 高级类型：进一步了解 newtype 模式、类型别名、never 类型和动态大小类型
- 高级函数与闭包：函数指针和返回闭包
- 宏：在编译时定义能够生成更多代码的代码

这是 Rust 各类功能的一次集中展示，每个人都能从中找到有用的内容！让我们开始吧！
