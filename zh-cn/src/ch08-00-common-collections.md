# 常见集合

Rust 标准库包含许多实用的数据结构，称为<em>集合(collection)</em>。大多数其他数据
类型表示单个特定值，集合却能包含多个值。与内置数组和元组不同，集合指向的数据
存储在堆上，因此数据量无须在编译期确定，并能在程序运行时增长或缩小。不同集合
具有不同能力和开销；为当前场景选择合适集合，是需要逐渐培养的技能。本章介绍
Rust 程序中最常用的三种集合：

- <em>向量(vector)</em>允许相邻存储数量可变的值。
- <em>字符串(string)</em>是字符的集合。前面提到过 `String`，本章将深入讨论。
- <em>哈希表(hash map)</em>把值与特定键关联起来，是更通用的<em>映射(map)</em>数据
  结构的一种具体实现。

其他标准库集合参阅[相关文档][collections]。

我们会讨论如何创建和更新向量、字符串与哈希表，以及每一种集合的独特之处。

[collections]: https://doc.rust-lang.org/std/collections/index.html
